# Шежіре ЕНТ 2027

Тренажёр к ЕНТ по истории Казахстана: 16 тем, более 1100 вопросов с подробным разбором, ключевые даты и пробный ЕНТ из 20 вопросов с переходом между вопросами.

- `index.html` — сайт (без сборки, открывается в браузере).
- `bank.json` — база фактов `[тема, тип, a, b, объяснение]`; из каждого факта генерируются два вопроса.

Вопросы тренировочные, составлены по школьной программе; это не задания реального экзамена.
